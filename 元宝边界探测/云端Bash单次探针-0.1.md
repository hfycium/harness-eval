# 云端 Bash 单次探针 0.1

类型：非基准能力探针，目标为观察元宝界面是否留存一次命令的请求和初始进程结果。与 Windows E8 分开记录，不计算 E8 或官方分数。此文件及提示词于提交前确定；不需要附件、本机文件或 Runner workspace。

## 交给元宝的提示词

```text
请只调用一次你实际提供的命令执行工具，原样执行以下命令。命令返回后不要重试、续跑或使用其他工具。请只依据工具的首次返回，分别报告可见输出、可见退出码及工具是否明确报告失败；不可见就写 unknown。不要根据命令内容猜测实际工具返回。

bash -c 'printf "PROBE_STATUS_OK\n"; exit 7'
```

## 独立判定

- 首先记录消息是否可见以及工具时间线是否明确显示一次调用、实际命令；界面只显示命令标题时不能补成请求详情。
- 分别查找独立的原始工具输出、退出码、失败状态。仅出现在助手答复中的数值或叙述，归为助手报告，不能充作工具返回。
- 工具结果不可见记 `unknown`；不重发、不轮询、不委托其他程序执行命令。本地可以计算提示词哈希并对界面证据做只读检查。
- 不提供或访问 E8 fixture，不访问本机目录。保留运行时间、产品入口、模式、截图或页面证据、提交状态和所有尝试；个人信息与凭据不归档。
