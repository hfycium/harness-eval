# 元宝无害工具探针（操作草案）

目的：在新会话中观察元宝是否展示真实代码执行工具的请求与初始返回。此探针只检查本次可见工具证据，不检验本机目录、Runner workspace、Windows `cmd.exe` 或 E8 准入，也不使用任何 E8 文件。

## 提交前

1. 在元宝的目标入口登录，记录网页或客户端、可见版本、模式和时间；新建空会话。手动查看工具入口，记录可见名称及说明。登录信息、Cookie 和个人资料不记录。
2. 将以下提示词原样发送一次，不上传文件：

```text
请使用你当前会话中实际提供的代码执行工具运行一次下列 Python 代码，并展示工具的原始调用和初始返回。如果没有可用执行工具，请直接说明无法运行，不要模拟结果。

print("YUANBAO_PROBE_7319")
```

3. 保留界面可见的请求和初始返回（截图或原始日志），注明来源；不要把模型回答转写成工具返回。此固定字符串是探针输入，模型能直接复述，所以即使回答包含字符串也不能证明执行。
4. 若看不到区分于助手回答的工具调用及返回，记 `unknown`。若明确没有工具，记录界面实际提示；不能据此推广到其他入口或版本。提交状态不明、工具超时或页面中断时停止，不重发，不由其他程序代运行。

## 判定与后续

- 可见真实调用和初始返回：记录调用内容、执行环境（若工具明确展示）及返回；只说明该次 Python 探针的可见事实，不推断 Bash、Windows 或本机工作区能力。
- 只有回答中的文字：调用和执行均为 `unknown`。
- 工具明确返回失败：如实记录该次探针失败；原因不清时为 `unknown`。
- 若后续需要核实 workspace 和 Windows，须另设计并登记无害探针，绑定同一 Runner run、元宝会话、工具和 workspace；本次探针不能充作该证据。

使用 [探针记录模板](探针记录模板.md) 记录。每次实际提交都是独立尝试；保持原始材料并记录人工操作，不覆盖历史记录。
