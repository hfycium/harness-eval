# 实时事件结构探针 0.1

独立非基准探针，用来检查单次无害 Bash 调用的实时响应是否包含可区分、可关联的工具返回结构。不得执行 E8 fixture、本机路径或重复调用。

```text
请调用当前会话的命令工具一次，原样运行以下无害命令；不要重试或使用其他工具。依据工具首次返回报告可见输出及退出码，看不到就写 unknown。

printf 'EVENT_SCHEMA_672341\n'
```

只记录实时事件的字段路径、类型、键名及有限的类型/状态元数据，不记录请求头、Cookie、模型思维过程或其他对话内容。工具返回必须能明确与本次命令关联；只看到事件名称、助手文字或语义不明的状态码时结果为 unknown。
