# WorkBuddy 本机会话证据采集试验

工具 `extract-session-evidence.mjs` 可在指定的 WorkBuddy 项目会话目录按 run ID 查找唯一 Bash 调用及对应返回，复制这一个工具事件到新的复核目录，记录源路径、文件 SHA-256、会话 ID、call ID 和行号。找不到、多个匹配或结果不唯一时停止。它不会复制完整会话，也不修改源文件或原运行。

在仓库根目录运行（将目录、ID 和输出目录换成本机实际值）：

```powershell
node .\automation开发\adapters\workbuddy\extract-session-evidence.mjs --projects-dir '<WorkBuddy具体项目会话目录>' --run-id '<run_id>' --output-dir 'runs/复核/<新目录>'
```

也可用 `--session <会话jsonl>` 替换 `--projects-dir`。当前只支持 Bash 命令参数中包含 run ID 的唯一一次调用；其他命令形式、多个匹配或非 Bash 工具不支持。读取本机用户目录可能需要当前用户权限。产物包含本机路径及命令内容，分享前须检查。

已在本机 E8 Bash 适配运行中成功按 run ID 定位并提取一次，见[证据](../../../runs/复核/workbuddy-session-auto-02/tool-evidence.json)。这是客户端本地会话事件，文件格式及对全部行为的覆盖尚未验证。

Runner 已增加可选接线：使用 `configs/workbuddy-queue-session-evidence.example.json`，并设置 `HARNESS_EVAL_WORKBUDDY_PROJECTS_DIR` 指向本机具体项目会话目录。Connector 收到提交后尝试采集一次匹配调用，失败记 unknown，不重发任务；已通过一次产品运行，见[实测记录](../../../runs/复核/workbuddy-session-automatic-2026-11-25.md)。Bash 适配题没有自动评分，默认队列配置不启用此功能。
