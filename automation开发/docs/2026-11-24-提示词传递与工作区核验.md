## 边界

- 每个任务使用隔离工作区，评分器和标准答案放在评测侧。Runner 在完成后记录输入文件前后哈希，仅表示两个时点的文件快照。
- Codex、DSH 结构化事件支持按文件和行定位部分调用与返回；不是操作系统级完整文件访问审计。旧 DSH 文本模式不能补出未记录的工具事件。
- 不拦截操作，也不声称可防住工作区外访问；产品沙箱和权限执行状态以实际证据为准。`.cmd` 执行需要解释器读取，不能简单通过禁止读文件实现只允许运行。
- 事件与会话可能包含产品输出、任务和本机路径，分享前需审查。原始 run 和原验收结果保持不变。
