# 元宝网页适配器：单次文本烟测

状态：首版 Runner 与元宝已完成一次人工辅助的文本烟测；自动点击产物预览是后续修改，尚待实测。当前只支持一个 TXT 产物，登录、模式、新对话、附件就绪、提交及完成均须操作员确认；网页版本与桌面端的等价性未知。

先关闭占用同一配置目录的 Playwright 探测浏览器。在交付仓库根目录 PowerShell 中执行：

```powershell
$env:YUANBAO_PROBE_PROFILE = 'F:\test\yuanbao-playwright\profile'
node .\automation开发\run-eval.mjs run --case .\cases\smoke\yuanbao-web-text\case.json --harness yuanbao-web --config .\automation开发\configs\yuanbao-web.example.json --timeout 900 --verify-text-artifact outputs/result.txt --verify-text-expected cases/smoke/yuanbao-web-text/input.txt --verification-output runs/复核/yuanbao-web-text-01
```

复核目录每次必须换成新名称。根据终端提示在元宝中操作：登录并选择专家模式、新建空对话；附件显示上传完成后确认；检查消息确已发出后确认；等待任务完成、确认产物卡片出现。每次输入 `y` 继续，其他输入停止。适配器尝试点击唯一 TXT 卡片打开预览，下载步骤使用之前观察到的 TXT 导出菜单；无唯一卡片时停止。若任务仍在进行、提交状态不明或出现错误，勿重复发送，保留当前 run 并人工排查。

Runner 归档与独立验证为两步调度。验证器按原始字节精确比较，已知元宝 TXT 导出可能缺少末尾换行，不能预设通过；本用例不产生 benchmark 分数。若关闭浏览器、页面选择器变化或登录过期导致失败，记录真实状态；XLSX、无人值守和自动完成检测均未实现。
