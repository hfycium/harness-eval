# 元宝网页适配器：单次文本烟测

状态：适配器支持单个 TXT/XLSX 文件往返，网页操作仍需人工辅助。登录、新对话、附件就绪、提交及任务完成须操作员确认；网页版本与桌面端的等价性未知。适配器会在发送任务前选择界面中的 Hy4 和专家模式，并检查 UI 选中标记；这不证明服务端实际生效模型。

适配器会在页面加载、附件前后、提交后和产物导出前检查可见弹窗。它只在可见对话框/弹窗容器内点击有明确关闭标签/类名的控件，或位于弹窗右上区域的 X/×；每轮最多关闭 3 个。未识别或仍未关闭的弹窗会保留给操作员处理，不使用坐标盲点。

登录并新建空对话后，适配器会点击“切换模型”，打开“选择模型”列表并选择 Hy4，再选择“专家模式 / 使用工具，处理多步任务”。适配器检查 Hy4 与专家模式选项的 `aria-checked` 均为 `true` 后才继续上传和发送；菜单项不唯一、无法选中或状态不能确认时会停止。`yuanbao-web-events.json` 记录界面选项状态；这只能证明 UI 选择状态，实际服务端模型仍为 unknown。

提交前会记录可见消息文本基线；提交后只采集相对基线新增且不等于本次提示词的页面文本块，写入 `visible_response_blocks`。这用于避免把提示词回显误认成回复。页面文本块的身份仍未由产品接口验证，因此记录为 UI 可见候选，不等同于原生工具 Trace；无新增文本时状态为 `no_new_non_prompt_text_observed`。

先关闭占用同一配置目录的 Playwright 探测浏览器。在交付仓库根目录 PowerShell 中执行：

```powershell
$env:YUANBAO_PROBE_PROFILE = 'F:\test\yuanbao-playwright\profile'
node .\automation开发\run-eval.mjs run --case .\cases\smoke\yuanbao-web-text\case.json --harness yuanbao-web --config .\automation开发\configs\yuanbao-web.example.json --timeout 900 --verify-text-artifact outputs/result.txt --verify-text-expected cases/smoke/yuanbao-web-text/input.txt --verification-output runs/复核/yuanbao-web-text-01
```

复核目录每次必须换成新名称。根据终端提示在元宝中登录并新建空对话；适配器会明确选择 Hy4，再检查专家模式已选中，随后确认附件显示上传完成、消息确已发出，并等待任务完成及产物卡片出现。每次操作员确认输入 `y` 继续，其他输入停止。若出现适配器未识别的弹窗，先由操作员判断并关闭，再继续。适配器尝试点击唯一 TXT/XLSX 卡片打开预览，按对应格式导出；无唯一卡片时停止。若任务仍在进行、提交状态不明或出现错误，勿重复发送，保留当前 run 并人工排查。

Runner 归档与独立验证为两步调度。验证器按原始字节精确比较，已知元宝 TXT 导出可能缺少末尾换行，不能预设通过；本用例不产生 benchmark 分数。若关闭浏览器、页面选择器变化或登录过期导致失败，记录真实状态。当前已在实际页面观察到 Hy4 和专家模式的选中状态；适配器自动执行该选择及弹窗关闭的完整流程仍需端到端核验。当前实现不代表无人值守，也不自动确认登录、上传、提交或完成状态。
