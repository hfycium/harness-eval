# 统一证据事件与 E8 复核

对已有运行离线转换；输出目录必须不存在，源文件和旧 run 不会被修改。客户端会话路径应由操作者明确指定，不要提交完整会话日志。

```powershell
node .\automation开发\runner\normalize-evidence.mjs --run-dir '<运行目录>' --source '<原始 JSONL 日志>' --output-dir '<新事件目录>'
node .\automation开发\scorers\score-normalized-e8.mjs --run-dir '<运行目录>' --events-dir '<事件目录>' --output-dir '<新评分目录>'
```

Codex、DSH 使用对应 run 下 `stdout.log`，转换器检查 trace 中的哈希；WorkBuddy、豆包工作使用本地会话 JSONL，通过唯一领取回执关联 run。输出事件保留源路径、哈希、行号和调用 ID，manifest 标记覆盖范围 unknown；工具返回仅保留涉及夹具的调用结果。

已用四款产品的历史 E8 日志跑通转换及复核；[样例：豆包工作](../../runs/复核/统一评分-doubao-03/verification.json)、[WorkBuddy](../../runs/复核/统一评分-workbuddy-03/verification.json)。评分器为实验版，检查字段、可见调用、工具返回和最终回复，尚未覆盖重复 JSON 键、所有过程约束或轨迹完整性；整体 unknown 不能视为通过。该步骤当前为独立命令，尚未接入 Runner 自动调度。

首轮 `统一评分-codex-01` 因按文件名误计写报告命令而错误判 failed；`*-02` 使用旧退出码匹配。记录保留用于追溯，以 `*-03` 为本次修正结果。工作版本采用非公开客户端日志格式，产品更新后需要重新验证。
