**术语边界：** MCP 是服务/工具协议；WorkBuddy 的 stdio Connector 是 WorkBuddy 桌面端连接器传输和产品配置方式；Runner adapter 是评测侧将产品生命周期映射到统一合同的代码。三者不能互相替代或从一款产品类推另一款。
