# 观测诊断使用

`configs/codex-account-observation.example.json` 可选启用账号模式本地会话诊断与工作区快照。启动用户必须已有 Codex CLI 登录；诊断运行不使用 `--ephemeral`，会把该次会话保存在该用户的 `CODEX_HOME`，其中可能含提示词和工具内容。Runner 只按本次 stdout 中的唯一 thread ID 定位并提取匹配消息、本地模型上下文字段和来源哈希，完整会话不会复制进运行目录。

运行目录 `codex-prompt-evidence.json` 的 `local_context_models` 是本地会话上下文，不等同服务端实际模型；`effective_model` 仍为 null。找不到会话、消息或匹配不唯一时记录 unknown。

`workspace-before.json`、`workspace-after.json` 包含评测工作区文件路径、大小和哈希，`workspace-changes.json` 比较两次快照；默认仅启用本诊断配置，其他配置可选择设置 `workspace_snapshot: true`。扫描限制 5000 个条目、总计 100 MB，不跟随符号链接；超限、无法读取或读取中变化记 partial。执行未完成时不拍摄结束快照以避免外部任务仍在运行。快照只反映两个时点，不能证明没有读取、中途修改后恢复或网络活动。

E8 统一事件 manifest v0.2 新增 JSONL 解析、调用返回配对、最终回复是否观察到等字段；解析失败或配对失败直接停止生成结果。`coverage` 仍为 unknown，采集完整不等同产品所有行为均已被观测。既有事件文件不回写。
