## 下一题候选：区分度与评分

SQL 作为简单链路基线保留，四款皆 6/6，区分度不足。优先候选为 TheAgentCompany `ds-format-excel-sheets`：官方 evaluator 有 4 个客观检查点，分别核对源表不变、目标数据一致、目标表头指定填色且其他填充保留、非空数据单元格居中。代码复核发现 checkpoint 3 对指定单元格缺少 solid fill 时只记 warning、没有返回失败，正式使用前需用独立严格检查器补足。原题依赖 OwnCloud，输入尚未取得，网页代码仍在 `main`、commit 未冻结；当前是待准入候选，未运行。[候选分析与官方来源](公开测试集候选.md)

后续候选 `ds-predictive-modeling` 使用 MSE、MAE、R² 阈值评分，复杂度更高，但数据与 gold 文件未取得，且结果更易混入模型能力影响；先不作为下一题。[候选分析](公开测试集候选.md#区分度任务建议2026-11-26)
