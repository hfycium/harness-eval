| 文件 | 用途 | 更新时机 |
|---|---|---|
| [五款产品评测总看板](五款产品评测总看板.md) | 跟踪当前接入、运行状态、阻塞和待办 | 新运行、接入状态变化、阻塞解决或待办进展时 |
| [五款产品评测总结](五款产品评测总结.md) | 汇总各产品评测结果、发现及证据边界 | 新结果经过验收，或出现有证据的新发现时 |
| [Harness评测方向](Harness评测方向.md) | 记录评测维度、实验思路和判断原则 | 调整维度、实验思路或判断原则时 |

| [TheAgentCompany SQL 四产品接入检查](TheAgentCompany-SQL四产品接入检查.md) | 记录 SQL 题的四产品接入、Trace、评分与自动化缺口 | 输入、适配或实测状态变化时，附证据更新 |

例如，选定一道公开题时更新测试集候选；产品运行后更新总看板；结果验收后将有价值的发现写入评测总结。无需每次运行都更新全部文件。
