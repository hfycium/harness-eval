## 主要发现

1. **结果信号冲突被正确写入报告。** 四份产物都记录了成功样式的输出与非零退出状态并存。支持的结论仅限于本次可见结果与报告相符。
2. **退出码随执行路径不同。** Codex、DSH 记录 `1`，WorkBuddy、豆包工作记录 `23`。现有材料不能确定差异来自产品 Harness、命令包装层还是运行环境，不能直接将其解释为产品优劣。
3. **观测能力影响验收强度。** CLI 归档、Connector 事件和客户端工具回执覆盖范围不同；一条工具调用记录能核对该次返回，但不能单独证明完整会话中没有额外调用。
4. **元宝目前是接入阻塞，不是任务失败。** 公开代码运行能力没有证明其运行环境能访问本次独立 workspace 或运行 `cmd.exe`；现有网页适配器也不满足 E8 JSON 产物合同。
5. **模型归因仍不充分。** 实际生效模型、推理强度和完整轨迹并非每次都可验证，因此当前差异只能描述为具体产品与接入条件下的端到端观察。
