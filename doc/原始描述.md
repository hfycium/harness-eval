课题作业公告
课题：每个人独立设计并产出一套 Harness 竞品评测的报告。方法不作限制，对照实验、任务复现、过程追溯或其他能够成立的路径均可采用。方案必须自圆其说：评测对象、观察指标、证据与结论前后一致；每一项判断都写明置信依据，并保证结论可以被复核。
要求：须提交个人开源的 Github 仓库代码链接，内容需要包含评测方案、相关用例、表现现场和打分细则，并据此完成书面竞品评测报告。比较对象为 Codex、Workbuddy、DSH、元宝专家模式和豆包办公。用例规定任务、输入与完成条件；表现现场记录各 Harness 执行同一任务时的实际过程与结果；打分细则规定观察项、赋分和判定标准。报告应依据上述材料，说明五款产品的差异、得分及理由。
注意：要设定，模型、SKILL、Harness 之间，要怎么归因定责，确保评测的主体是 Harness 而不会受其他变量干扰影响。
周报：每周六写一份个人工作周报邮件（含本周项目进展、本周难点突破、下周项目计划）发给以下发件人：
