# Harness 竞品评测

面向 **Codex、WorkBuddy、DSH、元宝专家模式、豆包办公** 的竞品评测作业仓库。评测主体是 Harness（任务组织、上下文、工具调用、权限、重试、状态、验证与交付机制），并显式控制模型、Skill、工具环境等混杂因素。

## 方法约束

- 每个用例写清**任务、输入、完成条件**；答案与检查器留在评测侧。
- 每次运行保留原始事件、产物、时间戳与 SHA-256；失败、未知、环境无效分别记录，不事后挑选代表轮。
- 打分细则在执行前冻结并标版本；证据不足记 `unknown`，不记 0 分或满分。
- 结论分三层：结果事实 / 行为诊断 / 因果归因。只有单因素对照成立时才给 Harness 因果结论，否则标 `unresolved`。
- 每条得分理由绑定结论卡，写明证据位置、置信依据、替代解释与外推边界。

完整工作约定见 [AGENTS.md](AGENTS.md)，需求原文见 [doc/原始描述.md](doc/原始描述.md)。
