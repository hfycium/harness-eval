# 四产品运行证据统一整理

## 目标

为 Codex、DSH、WorkBuddy、豆包工作的现有 E8 日志提供产品专属转换器，输出统一事件，供后续评分器使用。保留原始证据的定位信息及不确定性。

## 范围

- 优先支持当前实际见到的 CLI JSONL 和客户端会话 JSONL 格式；元宝缺少相应证据时记录为不支持。
- 提取工具调用、工具返回、最终回复与文件操作等可见事件，按原始调用 ID 关联，不推断未出现的结果。
- 提供独立转换命令，对旧运行生成新的复核文件；原始 run、trace、原始日志及已有评分不可覆盖。
- 明确事件来源、行号、源文件 SHA-256、转换器版本、时间和覆盖范围。无法获得完整证据或匹配不唯一时标记 unknown 或阻塞。
- 定义评分器接入边界；转换成功不等于题目通过。

## 验收

四种格式各使用真实历史日志检查，确保事件能回溯到源行，调用与返回匹配；缺失、格式错误、重复 ID 时不会伪造事件。仅提取必要事件，不复制完整会话或无关内容。旧运行与评分保持原状。
