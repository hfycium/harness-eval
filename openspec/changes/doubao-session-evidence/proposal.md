# 豆包工作本地工具证据采集

## 目标

为队列运行提供可选的本地轨迹采集，保存可追溯的 E8 工具调用和返回，不依赖产品回答中的自述。

## 范围与验收

- 只在显式开启 `session_evidence` 且配置本机会话根目录时采集 `tracetrial-e8-cmd`。
- 用领取回执中的 run ID 定位唯一会话，用工具调用 ID 配对唯一返回；多次调用、匹配不唯一或读取失败时记为 unknown。
- 保存匹配命令、工具返回、源文件哈希和行号，不归档完整会话。
- 保留现有队列执行与人工导入方式；采集结果仍需评分器或人工核验。客户端内部日志格式和覆盖范围未经官方保证。

## 实施状态

已实现队列适配器接线和独立提取器。已有历史 E8 运行回放成功；新任务提交后的自动采集尚未实机验证，评分器尚未消费该证据。
