# 设计

评测者从豆包工作界面导出或复制可见记录，保存为本地文本 → 豆包工作证据导入工具校验 run 的产品身份与 run/case 对应 → 写入独立复核目录 → 计算原文和运行记录摘要 → 生成来源为 operator_exported 的索引。

该记录是操作员提供的客户端展示内容；不等于 Runner 自动采集的原始工具事件，也不证明事件完整、内容真实或模型内部过程。若产品导出接口未确认，不假设可以自动导出。缺少导出文件时保持 unknown。

限制：输入不为空、大小受限；输出目录必须新建且与 run、源文件分离；不跟随输入符号链接写入，不改动来源和历史记录。仅导入豆包工作 run，出错时不声称通过。用户分享前自行检查可能包含的任务或敏感信息。
