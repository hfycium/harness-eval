# 元宝能力评测规划

## 背景

元宝网页适配器已有人工辅助 TXT 文件任务尝试。公开资料提及代码运行，第三方材料提及云端 Bash；当前会话是否实际提供这些工具及其调用证据仍未知。Windows E8 要求原生命令工具访问 Runner workspace 并执行 `cmd.exe`，现有元宝网页适配器没有该接入，也只支持单个 TXT 产物。详见 `元宝边界探测/计划.md`。

## 目标与范围

- 固定元宝实际入口、版本、模式和可见工具，先做不含基准题的能力盘点。
- 根据可观察到的能力，优先开展文件任务；必要时先做独立无害探针观察代码执行或 Bash 工具，确认后再设计相应适配题。
- 为每条路线冻结任务、输入、完成条件、证据要求和独立验收方法，保留全部尝试。
- 提升网页适配器对常见弹窗的恢复能力，并把 Hy4/专家模式作为明确的界面配置记录；不把界面选择误记为实际模型证明。
- 原 Windows E8 保持原题准入条件；云端 Bash 适配题单独编号、单独记录，不称为原题成绩或官方得分。

## 边界与验收

本变更先规划，不启动产品任务或修改冻结题目。会话工具和工作区访问未证实为 `unknown`；无原生命令工具及本次 Runner workspace 证据时，Windows E8 为 `not_admitted`，不领取。验收要求可复核的输入、提交、工具证据、产物及独立检查；缺失证据不补造，不据此作因果归因。文件任务与命令/代码任务的能力结论分别报告。
