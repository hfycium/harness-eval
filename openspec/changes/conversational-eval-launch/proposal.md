## 目标

完善现有 `harness-eval-launch` Skill，使评测侧 Agent 能根据对话选择用例、Harness 和可用模型配置，调用现有 Runner，解释各产品的人工步骤和结果。进一步设计批量调度脚本，支持选择产品、串行运行和可控并行。

## 范围

先修正 Skill 对五产品接入状态的过时描述，使单次运行指导与现有代码一致；批量调度分阶段实施，不把计划中的能力写成已实现。复用现有 Runner、产品适配器、评分与归档；模型请求与实际生效状态分别记录。

## 验收

Skill 可指导单次选择、模型配置、真实 run ID 交接和结果核对；批量功能实现后能选择一个或多个产品、逐项记录状态并汇总，明确人工阻塞和失败。真实产品的可用范围以运行证据为准。
