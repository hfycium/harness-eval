## 背景

元宝网页专家模式的探索已观察到 Playwright 选择附件和从文件预览下载 TXT；登录、进入对话和打开预览仍由操作员参与。输入与下载文件相差末尾换行，严格字节比较未通过。证据见 `automation开发/docs/元宝Playwright探索记录.md`；网页与既有桌面评测入口的等价性尚未确认。

## 目标

开发独立元宝网页适配器并注册到 Runner，先以人工登录及必要人工确认启动，打通单个合成文件任务的准备、上传、提交、可见状态监测、产物回收、独立验收与归档。随后验证 SpreadsheetBench 59196 的 XLSX 文件往返与现有评分器衔接。

## 范围边界

不实现定时任务或批量评测；不把网页结果标记为桌面端结果；不推测内部工具调用或 Trace。Excel 未验证前不得声称支持 Excel 自动下载与评分。人工协助与自动步骤分别记录。

## 验收

同一 run 的任务输入哈希、提交证据、完成观察、回收文件、评分与归档一致。合成文本的严格字节匹配及允许的文本规范化结果分别报告；末尾换行差异不自动视为严格通过。XLSX 单题另设准入与评分结果，不受合成任务成功的推定影响。
