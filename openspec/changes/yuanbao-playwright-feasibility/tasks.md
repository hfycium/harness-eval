## 可行性探索

- [ ] 启动可见浏览器，人工完成登录并确认专家模式；登录失败、验证或权限要求均如实记录。
- [ ] 只读检查输入框、附件、提交、完成状态及下载控件是否能稳定定位，记录证据和选择器来源。
- [ ] 准备无敏感内容的合成输入及明确期望产物，记录输入哈希。
- [ ] 上传文件并提交一次任务，记录提交证据、人工参与和状态；不确定是否提交时停止而不重复提交。
- [ ] 观察完成、失败或超时，下载产物，独立比对内容及哈希；分别记录各阶段结果。
- [ ] 检查登录失效、超时、下载失败和任务可能继续运行时的处理方案；没有实测的场景标记待验证。
