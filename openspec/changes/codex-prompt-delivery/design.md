# 设计

探针独立生成三个随机标记，放在提示正文开头、中间、结尾，并要求最终回复按顺序只返回标记、不要调用工具。每次生成独立任务目录和评测侧期望值；使用生产 Runner 和实际 Codex 配置启动，记录 prompt 哈希、适配器配置、标准输入传递方式和 Codex 结构化事件。

独立检查最终消息是否严格匹配预设标记及顺序；检查结构化日志中是否有工具调用，避免通过读取工作区中的 prompt.md 获得标记而冒充提示词接收。日志缺失、调用不明或消息不匹配需分别报告。该探针只证明本次特定标记到达并被产品使用，不能证明全文逐字符、所有系统内部步骤或其他运行已送达。

如果能获得本次产品原始初始用户消息，以安全方式只比对哈希或逐字符一致性；不可将其他人的凭据或私密会话原样归档。永久判断历史运行需历史消息和同一 run 身份可定位，不以新探针替代。
