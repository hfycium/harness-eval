## ADDED Requirements

### Requirement: 探针可复核

#### Scenario: 完整标记和无工具调用

- **WHEN** 单次运行的最终消息精确包含评测侧预设标记并按要求排序，结构化事件没有工具调用
- **THEN** 记录该次标记送达探针通过，并保留提示哈希和事件位置；不得宣称逐字符全文已验证。

#### Scenario: 证据不足或工具读取提示词

- **WHEN** 事件不完整、存在工具调用或响应不符合条件
- **THEN** 分别报告证据不足或探针未通过，不推定初始提示词已完整送达。

### Requirement: 保留历史边界

#### Scenario: 新探针成功

- **WHEN** 新运行完成探针
- **THEN** 不得使用新结果追认旧运行已完整接收任务。
