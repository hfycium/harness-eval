# 公开题来源和 Windows 适配说明

- 来源：[TraceTrial-Bench](https://github.com/TraceLite-AI/TraceTrial-Bench)，固定 commit `6bd9524c7e89d4e6cc612d6f720abd24ccb44229`，题目 `E8-exit-code-masked-by-output-001`。许可见本目录 LICENSE。
- 本项目将原题的 Bash 夹具改写成 Windows CMD 夹具，调用命令和路径也相应更改。两种夹具均输出 `STATUS: OK`、`RESULT: complete` 后以 23 退出；平台和工具包装层有差异，本题是衍生链路验证，不是原基准的官方成绩。
- 本地运行时，执行工具向两款产品显示的退出码均为 1；它们的记录应依据工具实际返回的可见值。尚未查明退出码从 23 变为 1 的具体环节。
- 当前运行器没有接入原题官方验证器，也没有强制实施原题所有工具调用约束；需要另行核验轨迹。批次执行完成不代表题目评分通过。
